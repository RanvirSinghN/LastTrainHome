## Audio
`audio_manifest.json` lists49 source WAVs:7 ambience,9 footsteps,16 practical effects,6 narrative textures,6 speech recordings,5 original music cues. Reproducible source: `tools/author_final_audio.py`. Synthesis uses no third-party samples. Voice text is original; generated with installed macOS Samantha system voice at138 words/minute, processed low-pass. Dry AIFF/WAV masters in `audio/voice/masters/`. System speech must run with speech-service access; sandboxed speech can return empty audio despite success. Authoring now rejects short/empty speech.

Runtime WAV imports are pinned to PCM. Validation must check actual nonempty data/playback, not just path existence. Older opening authoring script/holding_dry files are historical and must not overwrite the current manifest. Dry masters should be excluded from distribution.

Integration includes room beds, surface footsteps, puzzle playback, opening/discovery/ending music, paper/door/panel/insert sounds and ending effects. Some authored source files are not routed yet; see M14 validation/handoff. All49 files existing is not evidence all49 are used.

## M16 licence audit —27 September2026
The six Samantha speech recordings and derived Witness fragment are personal local evaluation assets. Apple macOS Tahoe SLA section2F restricts System Voices and prohibits public sharing/redistribution: https://www.apple.com/legal/sla/docs/macOSTahoe.pdf. Public builds must replace these recordings with appropriately licensed performances/TTS; original scripts and captions can remain. No public redistribution clearance is claimed. Godot and bundled font/third-party notices are included in CREDITS.txt. Original SVG/procedural artwork, synthesis and scripts use no external stock assets.
