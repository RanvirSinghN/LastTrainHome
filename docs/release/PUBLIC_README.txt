LAST TRAIN HOME — 1.0.0
Public macOS build • Written dialogue edition

PLAY
Extract the ZIP into a local folder such as Downloads and open
Last Train Home.app. Godot is not required to play the packaged app.

CONTROLS
A/D or arrows: walk. Shift: faster walk. E: inspect/talk.
Tab: cycle nearby targets. I: inventory. J: notebook.
P/Escape: pause. Mouse and keyboard operate menus.

Settings include text size, control remapping, fullscreen, volume,
reduced motion and reduced flicker. Losing focus pauses the game.

SAVES
Progress autosaves. Continue resumes the current journey. Reset Game asks
for confirmation, clears the journey, autosave, backup and ending checkpoint,
then starts fresh. Settings are retained.

AUDIO AND TEXT
All announcements, archived recordings and ending statements are written on
screen. The public build contains no recorded or synthesized speech. Music,
ambience and original sound effects remain.

TECHNICAL NOTES
Built with Godot 4.7.2 Standard using the Compatibility renderer.
The app is locally ad-hoc signed and is not Apple notarized. It was exercised
on Apple M4 / macOS 26.6.2. The binary also contains Intel code, though Intel
hardware has not been tested.
