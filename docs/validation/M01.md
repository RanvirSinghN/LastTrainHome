## Errors encountered and resolved

1. The filesystem sandbox prevented Godot from creating its normal user-data/editor-cache directories. Re-ran the engine with approved filesystem access; import then completed cleanly. This was an execution-environment restriction, not a game defect.
2. Initial arrow-key constants were wrong. Corrected Left/Right and verified both arrows plus A/D in the integration test. Added logical-key fallbacks so accessibility/synthetic events with no physical keycode also work.
3. The test initially inspected buffered input before delivery. Flushed the engine's input queue in the test helper; no gameplay timing workaround was added.
4. The export preset's custom template was ignored while advanced options were disabled, and the arm64 texture-import setting was absent. Enabled advanced options and the project S3TC/BPTC and ETC2/ASTC import settings; the export then succeeded.
5. Finder metadata on the extracted Desktop app caused strict signature verification to complain. Removed only `com.apple.FinderInfo` from that generated bundle; strict verification passed afterward. If file-provider software recreates that display metadata later, validate a fresh extraction outside the synced Desktop before diagnosing a code-signing regression.
