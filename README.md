# LastTrainHome

## Description

Last train home is a small indie experience I created for fun using gpt 6 astra in codex. The game is set in an isolated railway station late at night. You explore the station, speak to different characters, investigate objects, collect clues and solve environmental puzzles. Your dialogue choices and actions are remembered throughout the game and can change what you discover and which of the three endings you reach.
